Help and rules

How many people fit in a session?

Exactly 20. The server counts every booking, so a 21st person always goes to the waitlist.

What is the waitlist?

When all 20 mats are taken you can still join. You get a position number. Whoever joined first is booked first.

How do I get booked from the waitlist?

You do not need to do anything. When someone cancels, the next person in the queue is booked automatically and sees their code on My bookings.

What is the code for?

Show your 6-letter code to staff at the door. Each code works once.

Can I cancel?

Yes, from My bookings, any time before you are checked in. Your mat goes straight to the next person.

Why is my booking gone after I cleared my browser?

Your bookings are tied to this browser. Clearing site data removes that link, so keep your code safe.
